The **General** section under **System Configuration** contains several fields that display identification information and the current status regarding the DME.  Some sections and fields may be edited and updated while others are for informational purposes only.

  Use the General section under System Maintenance to display information and current status updates regarding your DME
</Image>

## DME Identification Fields

The **System Maintenance** section is used to identify a specific DME.  Most of them may not be edited.

<Image title="systemMaintenance.png" alt={756} align="center" src="https://files.readme.io/f849f65-systemMaintenance.png">
  System Maintenance fields are used to identify a specific DME
</Image>

The **Name**, **Location**, and **Contact** fields are used to identify the appliance. They are not changed when you click Default. (They *are* changed when you reset to the defaults on the **Manage Configuration** page.)

* **System Description:** Read-only. Company name and product name.

* **System Model Number:** 7530, 7550, or 7570.

* **System Serial Number:** Unique serial number assigned to unit. See label on DME.

* **System Licenses:** Displays whatever licenses are currently installed.

* **System Name:** User-defined. System name, for example Biology Dept.

* **System Location:** User-defined. System location, for example West Campus.

* **System Contact:** User-defined. Contact person, for example Jane Doe.
