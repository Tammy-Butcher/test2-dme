Stored **Video On Demand (VOD)** files are added to the DME via FTP.  The DME VOD servers support all of the file types shown in the table below.

<Table align={["left","left"]}>
  <thead>
    <tr>
      <th style={{ textAlign: "left" }}>
        VOD Server
      </th>

      <th style={{ textAlign: "left" }}>
        Supported File Types
      </th>
    </tr>
  </thead>

  <tbody>
    <tr>
      <td style={{ textAlign: "left" }}>
        RTP
      </td>

      <td style={{ textAlign: "left" }}>
        mp4, mov, m4a, m4v
      </td>
    </tr>

    <tr>
      <td style={{ textAlign: "left" }}>
        Multi Protocol
      </td>

      <td style={{ textAlign: "left" }}>
        flv, f4v, mp4, mov, m4a, m4v (H.264)
      </td>
    </tr>

    <tr>
      <td style={{ textAlign: "left" }}>
        HTTP
      </td>

      <td style={{ textAlign: "left" }}>
        all available files including M3u8 (HLS) and f4m (HDS)
      </td>
    </tr>
  </tbody>
</Table>
