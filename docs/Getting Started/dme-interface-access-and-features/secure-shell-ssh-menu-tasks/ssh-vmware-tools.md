## VMware Tools

If your DME is deployed as a VM on a VMware ESXi Host, then this task option will be displayed. It is not available and _will not_ be displayed for Vbrick/Cisco Hardware, or Microsoft Hyper-V DMEs. This task will return a number of VMware specific metrics including contention and memory use. Please see VMware documentation for specific details on each measure.
