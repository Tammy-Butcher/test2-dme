The Vbrick DME server has an integrated management interface (VBAdmin) that lets you manage the DME configuration from an external Web browser. This allows network managers to remotely configure and monitor the appliances from virtually any location that has Web access.

The most convenient way to access the VBAdmin interface through a [supported browser](doc:supported-browsers). Connect to VBAdmin by pointing to the **IP Address** and **Port Number** (for example:`http://192.168.5.5:8181`) of the DME and log in with valid credentials. 

By default the admin port for the DME is **8181**. This allows Port 80 to be reserved for HTTP downloads.
