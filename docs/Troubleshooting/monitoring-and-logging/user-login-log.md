The **Monitor** > **User Login Log** page keeps a record of all log ins to the DME. It will store up to 700 KB of information before it begins removing old records which equates to approximately 11,000 user records/logins. 

The **IP Address**, **Username**, date/time, and **Status** is tracked of each log in. This page will alert you to an unauthorized access (or an attempt) to your DME.
