The **Monitor** > **Access History** page displays the file names that have been requested by all users since the last DME reset.

It is enabled and rolls over (i.e. overwrites the information) as configured on the [Logging Settings](doc:logging-settings) page.

* **Files Requested**: File names requested since the last DME reset.

* **Requests**: Number of times the individual file was requested.
