The **Diagnostics** > **Traceroute Test** utility enables you to enter a domain name or IP (IPv4 or IPv6) to print the route packets from the DME to a specific host.

* **Destination**: Domain name or IP (IPv4) to traceroute test.

![716](https://files.readme.io/4961b32-tracerouteTest.png "tracerouteTest.png")
